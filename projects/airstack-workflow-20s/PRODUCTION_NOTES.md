# AIR STACK — THE WORKFLOW | Production acceptance

This project follows the BKE Kinetic Motion v2.2 pipeline. The only acceptable final deliverable is the
full-gated 20.000-second 1920×1080 H.264 MP4 at 60 FPS with its reproducible source, manifest,
synchronized original music, QA reports, and motion previews.

## Narrative

Repetition → connection → reusable structure → updated data → automation → broadcast → brand.
Keep the broadcast application separate from Air Stack: Air Stack supports its preparation workflow.

## Ranked impacts

1. 17.500 s — brand payoff; the camera has stopped
2. 15.000 s — decisive broadcast-output activation
3. 05.500 s — luminous connection propagation and work reorganization

## Creative review after the preview gate

- Watch actual motion windows at 0–4, 4–7, 7–11, 11–15, 15–17.5, 17.5–20 seconds, not only contact sheets.
- Without typography or sound, repeated isolated tasks must visibly become a single reusable operational graph.
- Keep one coherent camera space: pullback → lateral track → push-through → arc → output → stop.
- The existing graph must remain structurally unchanged when fresh program data enters it.
- Prevent unintended holds during the 4–7 s transition: one source panel stops, surrounding repetitions continue.
- Inspect module-lock stagger, focus, readability, perspective, masking, 3D occlusion, and false camera-only motion.
- Confirm all required audiovisual impacts align with the timeline; actual VERIFIED rows must pass.
- Confirm the final brand composition is static and legible through frame 1199.
- Any gate FAIL is a production failure; do not distribute a QA-only artifact as a final MP4.

## Approved production process

1. PR preview render and full v2.2 gate.
2. Iterate on measured issues and inspect moving preview clips.
3. Merge only when checks and the temporal creative review pass.
4. Run final GitHub Actions S=2 render on main; download only gate-approved output.
